## Зависимости

В `package.json` объявлены React / ReactDOM 19, R3F 9, Drei 10, Three.js, three-stdlib, Motion for React, Fontsource Cormorant Garamond и Manrope. Для разработки: Vite, TypeScript, React plugin, определения типов.

**Успешно установленных зависимостей в новом проекте нет.** Сетевые попытки завершились `ENOTFOUND registry.npmjs.org`; offline-попытка — `ENOTCACHED` для отсутствующих пакетов. Не создавался фиктивный lockfile. Имеющиеся инструменты другого проекта использованы только для ограниченной проверки синтаксиса; его файлы и зависимости не изменялись.

## Что осталось до завершения

1. Установить зависимости при доступном npm: `npm install` из папки `CHRONOS/web`.
2. Запустить typecheck и production build, исправить найденные интеграционные проблемы.
3. Запустить Vite и проверить реальный GLB: ориентацию, композицию, металл, прозрачность стекла, читаемость циферблата, отражения.
4. Проверить консоль, network, мышь/касания и клавиатуру, отсутствие горизонтального скролла от 320 px.
5. Проверить reduced motion, ошибку GLB, отсутствие WebGL и потерю контекста, остановку GPU вне экрана/вкладки.
6. Проверить Safari macOS и реальное iOS-устройство. Измерить мобильную производительность.
